title: "Events"
subtitle: "Upcoming meetups, workshops, and conferences for people working in university and research institution OSPOs."
---

Events run by CURIOSS, and events from across the academic open source community that we think our members will want to know about. There is also an [RSS feed](index.xml) you can subscribe to.

To suggest an event, use the **Suggest an event** button below the list. It opens a GitHub issue you can fill out, and maintainers will add accepted events via pull request.
